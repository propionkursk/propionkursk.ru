# propionkursk.ru — контекст проекта

Питомник пионов. Цель: пересобрать сайт с одностраничника на многостраничный
каталог сортов по стандарту из `MASTER-PEONY-001_propionkursk_master_standard.md`
(читай этот файл первым при любой задаче, связанной с карточкой сорта).

## Источник истины

- `_data/peonies.yml` — единственный источник данных по сортам.
- MASTER-документ — единственный источник архитектурных решений.
  Если что-то в коде противоречит MASTER-документу — прав MASTER-документ,
  не существующий код.

## Жёсткие правила (не нарушать)

- Никогда не выдумывать факты о сортах (селекционер, страна, год, диаметр
  и т.д.). Если данных нет — оставлять `null`, а не подставлять правдоподобное.
- Никогда не показывать цену, если `price_rub` не заполнено. Никаких плейсхолдеров
  вида «уточняйте».
- Не создавать корзину/оформление заказа — коммерция только через
  WhatsApp/Telegram со ссылкой из `sale.division`.
- Формат фото карточек и каталога — строго 1:1.
- Один доминирующий CTA на экран (см. раздел 10 MASTER-документа).
- Badges — полностью автоматическая генерация, без ручного выбора
  (см. раздел 7.1 MASTER-документа).

## Текущее состояние

- Старый сайт — одна HTML-страница со списком из 16 сортов, без корзины,
  контакты — телефон/WhatsApp/Telegram/VK.
- `_data/peonies.yml` — черновик, перенесённый из текста старого сайта.
  Много полей `null` намеренно — это не баг, а честное отсутствие данных.
  Смотри комментарии `# TODO` в файле.
- Ещё не решено: на чём технически собран текущий сайт (Jekyll/иное) —
  первая задача каждой новой сессии — это выяснить.
